Instinct MI355X

Compute organization

Each XCD exposes 32 compute units (256 in total) at up to 2.4 GHz. A CU contains four matrix cores alongside its SIMD vector units, 512 KiB of vector registers and 160 KiB of local data share (LDS). The gfx950 ISA adds MXFP4/MXFP6 matrix formats.

The XCDs are 3D-stacked onto two mirrored I/O dies, which carry the Infinity Fabric, Infinity Cache and memory controllers.

Memory orchestration

The hierarchy is hardware-managed: 32 KiB vector L1 per CU, 4 MiB L2 per XCD (32 MiB total), and a 256 MiB last-level Infinity Cache (memory-attached) in the I/O dies in front of eight HBM3E stacks. LDS offers explicit staging inside each CU.

Interconnect & system scale

Seven Infinity Fabric links at 144 GB/s connect eight GPUs all-to-all on a UBB 2.0 baseboard; a PCIe Gen 5 x16 link goes to the host. Larger clusters scale out over Ethernet/RoCE NICs.

Programming & scheduling

ROCm/HIP; wavefronts of 64 lanes scheduled dynamically. The GPU can be partitioned into 1 or 4 physical partitions and up to 8 SR-IOV virtual functions.

Why class A1

SIMD wavefront execution with matrix cores and a deep hardware cache hierarchy.
