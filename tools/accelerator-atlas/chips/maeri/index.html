MAERI

B2 B · Tensor-engine-centric — Flexible tensor datapaths

MAERI (Georgia Tech, ASPLOS 2018) builds a DNN accelerator from tiny configurable switches instead of a fixed PE array. A distribution tree multicasts operands to a row of multiplier switches; an augmented reduction tree sums their products. Because both networks are reconfigurable, multipliers can be grouped into 'virtual neurons' of any size, keeping utilisation high across irregular layer shapes.

Compute organization

Multiplier switches (MSs) sit in a 1D row and can either multiply or forward partial sums. A virtual neuron (VN) is a contiguous group of MSs that computes one output; its size follows the tile of the filter, so a 3×3×C filter and a fully connected row can both map without padding to a fixed array size.

Memory orchestration

A prefetch buffer feeds the distribution tree and stores partial sums when a filter is too large for one VN (folding): the partial sum is sent back through a forwarding MS and reduced with later results.

Interconnect

The distribution network is a bufferless binary tree that can unicast, multicast or broadcast in one traversal. The reduction network is a tree of adder switches with extra horizontal links between neighbouring nodes that have different parents; those links let several VNs reduce simultaneously without blocking each other. Each adder switch can add two or three inputs, or add one and forward another.

Why class B2

A tensor compute array whose dataflow is set by reconfigurable on-chip networks — closer to a flexible tensor datapath than to a general CGRA.
