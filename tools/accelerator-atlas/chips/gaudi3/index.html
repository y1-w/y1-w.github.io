Gaudi 3

B2 B · Tensor-engine-centric — Flexible tensor datapaths

Intel's Gaudi 3 splits work between two kinds of engine: eight large matrix-multiply engines (MMEs, each a 256×256 systolic array) and 64 programmable Tensor Processor Cores (TPCs) for everything else. Two 5 nm compute dies share 96 MB of on-die SRAM, 128 GB of HBM2e and 24 integrated 200 GbE RoCE ports for scale-out without separate NICs.

02Architectural analysis

Compute organization

The chip is divided into four DCOREs (two per die). Each holds two MMEs — 256×256 output-stationary MAC arrays with FP32 accumulation (64K MACs/cycle) — and sixteen TPCs. A TPC is a VLIW SIMD core with a 256-byte vector unit, a 12 KB vector register file and 80 KB of local memory, programmed in a C-like TPC language for non-GEMM operators.

The two dies are joined by an interposer bridge and appear as one device.

Memory orchestration

Each TPC has software-managed local memory. The 96 MB shared SRAM acts as an L2-style buffer between engines and HBM; the graph compiler controls much of the placement, so the atlas records the memory model as mixed (on-chip SRAM + HBM).

Interconnect & system scale

Forty-eight 112G PAM4 SerDes form 24 × 200 GbE RoCE ports, used both inside an 8-card OAM baseboard and for scale-out through standard Ethernet switches. The host link is PCIe Gen 5 x16; fourteen media decoders handle image/video ingestion.

Programming & scheduling

PyTorch via the Intel Gaudi software stack; a graph compiler assigns GEMMs to MMEs and fuses elementwise work into TPC kernels, overlapping the two engine types.

Why class B2

Dedicated tensor engines plus programmable vector cores and configurable local storage — a flexible tensor datapath.

05Evidence & caveats

Read before comparing
  • 900 W on OAM SKU per product sheet; PCIe version differs.
  • 900 W applies to the air-cooled OAM; liquid-cooled OAM is 1,200 W and the PCIe card is lower.
  • Intel's material calls the 96 MB SRAM an L2 cache; the compiler can manage it explicitly, so the atlas records a mixed memory model.
