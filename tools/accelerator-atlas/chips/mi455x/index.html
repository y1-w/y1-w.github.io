Instinct MI455X

A1 A · Instruction-driven — SIMT / vector–tensor processors

AMD's CDNA 5 flagship for the Helios rack. Eight accelerator complex dies (XCDs) on TSMC 2 nm are hybrid-bonded onto two Fabric and Cache Dies (FCDs) on N3P, giving 320 billion transistors, 256 work-group processors (WGPs), 192 MB of L2 and twelve HBM4 stacks totalling 432 GB at 23.3 TB/s.

02Architectural analysis

Compute organization

AMD renamed the compute unit to the work-group processor (WGP). MI455X keeps MI355X's count of 256 but changes the wavefront width from 64 to 32 lanes and doubles the transcendental unit's throughput (adding a native tanh). Peak low-precision matrix throughput is roughly 2–4× MI355X depending on format.

Each FCD carries four XCDs bonded directly on top of it (3D hybrid bonding), so the XCDs talk to cache and memory through vertical connections rather than across an organic substrate.

Memory orchestration

The Infinity Cache of CDNA 4 is gone. Instead, each FCD holds a 96 MB shared L2 slice (192 MB total) with about 1.5× the per-die bandwidth of CDNA 4's Infinity Cache. Local data share (LDS) per WGP doubles to 320 KB.

A Tensor Data Mover can copy tiles directly from HBM into a WGP's LDS and memory reads support multicast — features that push this cache-based GPU toward explicit, compiler-staged data movement.

Interconnect & system scale

Each FCD links to six HBM4 stacks, two I/O dies and its sibling FCD over TSMC CoWoS-L. In Helios, 72 MI455X GPUs form one coherent scale-up domain (UALink-over-Ethernet in the dataset record), with Ethernet scale-out.

Programming & scheduling

ROCm/HIP with dynamic wavefront scheduling; tensor kernels come from hipBLASLt, Composable Kernel, Triton and framework compilers.

Why class A1

Wavefront-scheduled SIMD lanes plus matrix engines, with hardware-managed L2 as the primary on-chip store. The 192 MB is cache, not scratchpad.
