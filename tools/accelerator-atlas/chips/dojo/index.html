Dojo D1

C2 C · Spatially distributed — Distributed-memory spatial manycores

Tesla's D1 was the building block of the Dojo training supercomputer: a 645 mm² TSMC 7 nm die holding a 2D array of 354 processing nodes, each a small CPU-like core with 1.25 MB of SRAM and no caches. Twenty-five D1 dies were bonded into a 5×5 training tile whose edges connected directly to neighbouring tiles.

02Architectural analysis

Compute organization

A Dojo node is an out-of-order-lite core with 4-way SMT on both scalar and vector schedulers, a 64-byte SIMD unit and 8×8×4 matrix-multiply units. Nodes are arranged as a 2D array and communicate over a mesh with single-cycle hops (256 GB/s per row and column).

Memory orchestration

Each node's 1.25 MB SRAM (400 GB/s load, 270 GB/s store) is the only on-chip storage; there are no caches, and software moves data between nodes explicitly. Bulk DRAM (160 GB per tile) sits behind Dojo Interface Processors at the tile edges.

Interconnect & system scale

Die edges expose 2 TB/s each, so the mesh continues seamlessly from die to die inside a tile and from tile to tile across the system plane.

Status

Historical reference: Tesla reportedly wound down the Dojo programme in August 2025. Specifications come from the 2021–2022 AI Day and Hot Chips disclosures.

Why class C2

Locally programmed cores with private SRAM and explicit mesh communication — a distributed-memory spatial manycore.
