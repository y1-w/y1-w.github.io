SN50 RDU

C1 C · Spatially distributed — Reconfigurable spatial fabrics / CGRA

SambaNova's fifth reconfigurable dataflow unit (RDU). Two maximum-reticle logic dies hold a sea of pattern compute units (PCUs) and pattern memory units (PMUs) joined by a programmable switch fabric; the compiler maps a model's dataflow graph spatially onto it. Memory is fully software-managed across three tiers: 432 MB on-chip SRAM, 64 GB HBM2E and up to 512 GB DDR5.

Compute organization

The RDU lineage descends from Stanford's Plasticine (see that record): PCUs are pipelined SIMD datapaths, PMUs are banked scratchpads with address generators, and switches route data between them. A model is compiled into a spatial pipeline so that successive operators run simultaneously on different regions of the chip, with intermediate tensors streaming between PMUs rather than round-tripping through DRAM.

Memory orchestration

There is no hardware memory management. SRAM holds the working set of the current pipeline stage; HBM2E holds active weights and KV cache; DDR5 holds many models' weights so the system can switch between models or experts quickly. SambaNova notes that SRAM usage does not scale with model size, because weights stream through it.

Interconnect & system scale

Scale-up uses 800 GbE and scale-out 400 GbE. Eight sockets connect all-to-all; at 64 sockets scale-up runs through Ethernet switches; at 512 sockets scale-up and scale-out merge. SambaNova also deploys SN50 for decode behind GPUs doing prefill (heterogeneous disaggregation over RoCE).

Programming & scheduling

SambaFlow compiles PyTorch graphs to a spatial configuration: placement of operators onto PCU/PMU regions, switch routes and DMA schedules are fixed at compile time and reconfigured between graph sections.

Why class C1

Computation is mapped spatially onto configurable compute and memory units linked by a programmable interconnect — the reconfigurable spatial-fabric (CGRA) subclass.

05Evidence & caveats

Read before comparing
  • Three-tier memory with up to 512 GB DDR5 (external); 64 GB HBM2E and 432 MB SRAM.
  • PCU/PMU counts, HBM bandwidth and power were not given in the Hot Chips 2026 coverage.
  • Performance-at-scale figures (e.g. ~40% memory-bandwidth utilisation at 512 RDUs) are vendor-reported.
