Jalapeño

B2 B · Tensor-engine-centric — Flexible tensor datapaths

OpenAI's first in-house inference chip, co-developed with Broadcom. OpenAI has published benchmark results and power figures but not a datasheet: compute layout, memory capacities, process node and interconnect bandwidth are undisclosed. What is known is the design intent — a 'fungible' accelerator that serves both prefill and decode, with model state such as the KV cache explicitly placed and kept local.

02Architectural analysis

What has been disclosed

OpenAI describes chip, memory, network, software and rack as designed together. The network is called integral to the architecture: a large communication domain lets a whole serving workload stay inside one connected system. AI-assisted optimisation of arithmetic circuits was used to pack in more compute.

First results on GPT-OSS 120B, DeepSeek R1 and Kimi K2.5 report 1.5–1.9× more throughput per kilowatt at peak and 1.7–3.6× lower end-to-end latency than the comparison GPU systems.

What is not disclosed

Core counts and organisation, peak FLOPS, on-chip SRAM capacity, HBM type and capacity, process node, packaging, scale-up topology and bandwidth. The atlas therefore draws no floorplan: the figure below is a disclosure map, not an architecture diagram.

Why class B2 (provisional)

Explicit placement of model state and a balanced prefill/decode design suggest a flexible tensor datapath with software-managed locality. The classification will be revisited once a technical disclosure appears.

05Evidence & caveats

Read before comparing
  • Precise SRAM, HBM size, die node and scale-up BW omitted: vendor announcement does not give a complete public datasheet. 700 W rated, measured ≤550 W sustained in cited tests. Classification B2 provisional.
  • Benchmarks are vendor-published; comparison systems and configurations should be checked in the source before quoting ratios.
  • Package TDPs cited by OpenAI for comparison GPUs (1,200 W GB200, 1,400 W GB300) are not like-for-like with a 700 W chip rating.
