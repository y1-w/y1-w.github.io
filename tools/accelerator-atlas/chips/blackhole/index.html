Blackhole (p150b)

C2 C · Spatially distributed — Distributed-memory spatial manycores

Tenstorrent's Blackhole is a manycore of Tensix cores on a 2D network-on-chip. Each Tensix pairs five small RISC-V controllers with a matrix engine, a vector engine and 1.5 MB of private SRAM; there are no caches between cores. The p150 cards expose 120 Tensix cores, 32 GB of GDDR6, sixteen large RISC-V CPU cores and 800G Ethernet ports for direct card-to-card scale-out.

02Architectural analysis

Compute organization

A Tensix core is a small pipeline in itself: five 'baby' RISC-V cores each own a stage — moving data in from the NoC, unpacking, driving compute, packing, and pushing results out. The matrix FPU handles tile matmuls and the SFPU handles vector/elementwise work.

Tensix cores sit in a 2D grid with DRAM, Ethernet and PCIe tiles at the edges. A February 2026 firmware update reduced the advertised p150 count from 140 to 120 enabled cores.

Memory orchestration

Each core's 1.5 MB L1 is a software-managed SRAM, not a cache. Kernels explicitly read and write tiles between L1s and DRAM over the NoC, using circular buffers to overlap movement with compute.

Interconnect & system scale

On-chip NoCs carry data between cores and to the edge controllers. Off-chip, Ethernet ports link cards and Galaxy servers directly in a mesh, so the same explicit-message model extends across chips.

Programming & scheduling

Open-source TT-Metalium exposes separate reader, compute and writer kernels per core; TT-NN and TT-Forge/MLIR sit above it.

Why class C2

Locally programmed cores with private SRAM and explicit network communication — the distributed-memory spatial manycore subclass.
