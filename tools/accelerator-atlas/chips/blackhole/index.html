Blackhole (p150b)

C2 C · Spatially distributed — Distributed-memory spatial manycores

Tenstorrent's Blackhole is a manycore of Tensix cores on a 2D network-on-chip. Each Tensix pairs five small RISC-V controllers with a matrix engine, a vector engine and 1.5 MB of private SRAM; there are no caches between cores. The p150 cards expose 120 Tensix cores, 32 GB of GDDR6, sixteen large RISC-V CPU cores and 800G Ethernet ports for direct card-to-card scale-out.

02Architectural analysis

Compute organization and register dataflow

A Tensix tile has five small RISC-V control cores, not five arithmetic engines. BRISC/NCRISC typically run reader/writer data-movement kernels; TRISC0, TRISC1 and TRISC2 command the unpacker, matrix FPU/vector SFPU and packer, respectively. A compute kernel is compiled into separate TRISC binaries and synchronized explicitly.

Unpacking converts L1-stored tile formats into compute formats and loads SrcA/SrcB (matrix operands) or Dst; the FPU computes into Dst. The SFPU uses Dst and its own LReg for elementwise and nonlinear processing. The packer converts Dst results back to L1. The SFPU is an optional branch of compute, not an obligatory stage following every FPU operation.

SRAM, tensor layout and DMA

Tensix L1 is a software-managed 1.5 MB SRAM scratchpad, not a conventional hardware cache; 180 MB is the aggregate across 120 enabled cores rather than a single shared pool. Circular buffers reside in L1 and act as producer/consumer queues between independent reader, compute and writer kernels.

Tensors typically use 32×32 element tiles. TensorAccessor is a software utility that maps a page or tile index under an interleaved or sharded layout to a target DRAM bank or remote L1 tile. RISC-V programs calculate addresses and issue asynchronous NoC DMA operations to the on-chip NoC interface; barriers and circular-buffer reserve/push/wait/pop calls coordinate data readiness. Unlike SambaNova, there is no separate PMU executing tensor-address patterns.

Network topology and chip-level heterogeneity

Blackhole provides two physically separate NoCs, each forming a 2D torus over the heterogeneous tile grid (Tensix, DRAM-interface, CPU, Ethernet, PCIe and management tiles). These NoCs carry on-chip reads, writes, multicast and atomic transactions; a flit is 512 bits (64 bytes). The on-chip NoCs are distinct from the off-chip Ethernet links.

The full ASIC has 140 Tensix sites, 24 DRAM access tiles corresponding to eight 4 GB GDDR6 controller groups, and four CPU-cluster tiles holding sixteen SiFive X280 cores. The P150b board has four QSFP-DD 800G inter-card Ethernet ports. Each CPU cluster is coherent with caches, unlike the software-managed Tensix L1 memory.

Software scheduling and overlap

TT-Metalium exposes explicit data-movement kernels, compute kernels, circular buffers and synchronization. A typical tile pipeline prefetches into an L1 input buffer with BRISC, computes with TRISCs and drains an L1 output buffer with NCRISC; these kernels can execute concurrently, although barriers and data dependencies determine the actual overlap.

TT-NN and TT-Forge provide higher-level tensor operations and compiler lowering. Interleaved placement distributes pages across storage banks; sharded placement makes tensor locality explicit across Tensix L1s. The dataflow is therefore programmable rather than a fixed systolic stream, but congestion, SRAM footprint and synchronization can limit performance.

Why class C2

A spatial manycore with software-managed per-core SRAM and explicit NoC data exchange. A meaningful comparison with SambaNova's PCU–PMU pair is the whole Tensix tile, including its RISC-V controllers, DMA/NoC paths, SRAM and tensor datapaths.

05Notes & references

  • All three architecture figures show functional groups, not silicon floorplans; the position of 20 dimmed Tensix sites in Figure 1 is illustrative only.
  • The current P150b card specification lists 120 enabled Tensix cores and 180 MB SRAM. The architecture/ISA overview also describes 140 physical Tensix sites and contains a legacy p150 count of 140; treat product-specific counts as authoritative for the P150b.
  • The memory hierarchy's NoC/Ethernet entry is a communication tier, not an additional memory-capacity level. NoC flit size does not equal sustainable end-to-end tensor bandwidth.
  • Blackhole's Tensix SRAM is software-managed, but SiFive X280 CPUs have private L1/L2 caches and shared cluster L3; the phrase 'no caches' should not be generalized to the entire chip.
