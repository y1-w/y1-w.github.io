HC1 demonstrator

D1 D · Model-specialized — Model-compiled datapaths

Taalas's HC1 is a model-compiled chip: the parameters of one network — Llama 3.1 8B — are embodied in the circuitry of an 815 mm², 53-billion-transistor TSMC 6 nm die instead of being loaded from memory. Removing the weight-fetch bottleneck lets a single user reach roughly 17,000 tokens per second, at the cost of supporting only that model (plus LoRA adapters).

02Architectural analysis

Compute organization

Instead of a programmable matrix engine that reads weights, HC1's datapath is generated for the specific network, so multiplying by a weight becomes fixed logic. Taalas reports a custom 3-bit base data type mixed with 6-bit parameters in this first generation.

Memory orchestration

There is no weight memory hierarchy at all — the 'memory model' is the circuit. Only activations and the KV cache need storage; context length is configurable and LoRA adapters can be applied for fine-tuning. On-chip SRAM capacity for KV state was not stated.

System & roadmap

The demonstrator is a ten-card server rated at 2.5 kW. A second, mid-sized reasoning model on HC1 silicon and a denser HC2 platform (moving to standard 4-bit floating point) were announced for later in 2026.

Why class D1

Architecture and weights are physically specialised for one model — the model-compiled datapath subclass, at the extreme end of the design-space axis for programmability.

05Evidence & caveats

Read before comparing

  • Throughput is vendor-reported; independent tests ranged from ~15,000 to ~20,000 tokens/s depending on prompt.
