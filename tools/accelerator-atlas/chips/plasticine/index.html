Plasticine

C1 C · Spatially distributed — Reconfigurable spatial fabrics / CGRA

Plasticine (ISCA 2017, Stanford) is a coarse-grained reconfigurable architecture designed to execute 'parallel patterns' such as map, reduce and filter directly in hardware. A 16×8 checkerboard of Pattern Compute Units and Pattern Memory Units, joined by a static switch network, gives 12.3 single-precision TFLOPS and 16 MB of scratchpad in 113 mm² at 28 nm.

02Architectural analysis

Compute organization

A PCU is a 16-lane SIMD pipeline with six reconfigurable stages; values flow stage to stage through pipeline registers and lanes can perform cross-lane reductions. Counters and control logic let a PCU implement a nested loop of a parallel pattern on its own.

Units are connected by word-level, vector and control networks of statically configured switches, so a whole program is laid out spatially as a pipeline.

Memory orchestration

Each PMU holds a 256 KB scratchpad in 16 banks (matching the PCU lane count) with configurable address decoders, so banking schemes such as strided or duplicated layouts are chosen per program. Off-chip access goes through 34 address generators and 4 coalescing units to four DDR channels (51.2 GB/s in the simulated DDR3 setup).

Area breakdown

PCUs take about 48% of the die, PMUs 30%, interconnect 17% and memory controllers 5%. Inside a PCU, functional units dominate (73%); inside a PMU, the scratchpad itself is ~90%.

Legacy

Plasticine's PCU/PMU vocabulary carries directly into SambaNova's commercial RDUs (see the SN50 record).

Why class C1

Spatial mapping onto configurable compute and memory units with programmable interconnect — the reference example of the CGRA subclass.
