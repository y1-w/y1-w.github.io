Eyeriss

B1 B · Tensor-engine-centric — Structured tensor arrays

Eyeriss (MIT, ISSCC/ISCA 2016) is the canonical spatial DNN accelerator for studying dataflows. A 12×14 array of 168 processing elements, each with tiny private scratchpads, implements the 'row-stationary' dataflow that maximises reuse of filters, input activations and partial sums close to the MACs; a 108 KB global buffer and run-length compression reduce DRAM traffic.

Compute organization

Each PE has a 16-bit MAC, control logic and three scratchpads — filter weights (224 × 16 b), input feature-map rows (12 × 16 b) and partial sums (24 × 16 b). In the row-stationary dataflow, a PE computes a 1D convolution of one filter row with one input row; rows of PEs then accumulate partial sums vertically to form 2D outputs.

Layers whose shapes do not fit the physical array are folded and replicated by the configuration.

Memory orchestration

The hierarchy is fully explicit: DRAM → global buffer → PE scratchpads → registers. The paper's energy analysis shows that moving data from DRAM costs orders of magnitude more than a MAC, which motivates keeping reuse inside the PEs. Zero-skipping and run-length coding exploit ReLU sparsity.

Interconnect

Global input and output networks deliver data from the buffer to PEs using row and column ID tags, enabling flexible multicast; a local network passes partial sums between vertically adjacent PEs. Eyeriss v2 (2019) replaced this with a hierarchical mesh to handle compact and sparse networks.

Why class B1

A structured spatial PE array with compiler/configuration-managed reuse — classified with tensor-array designs, though it is the archetype for spatial dataflow analysis.
