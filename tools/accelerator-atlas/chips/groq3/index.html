Groq 3 LPU

C3 C · Spatially distributed — Deterministic streaming processors

The Groq 3 LPU (LP30), now sold by NVIDIA in the LPX rack alongside Vera Rubin, is a deterministic streaming processor. Compute, memory access and chip-to-chip communication are all scheduled by the compiler in advance; there is no HBM and no cache — 500 MB of flat on-chip SRAM at ~150 TB/s is the working store.

02Architectural analysis

Compute organization

Execution is divided among functional modules: MXM for dense matrix multiply-accumulate, VXM for pointwise arithmetic, type conversion and activations, and SXM for structured data movement such as permute, rotate and transpose. Every operation works on 320-byte vectors that stream between modules and memory on a fixed schedule.

In the Groq lineage these modules are laid out as vertical slices across the die, with instructions flowing one way and data streams flowing across slices; the figure shows that arrangement conceptually.

Memory orchestration

Weights, activations and KV state are placed in SRAM by the compiler and runtime. Because there are no caches or dynamic arbiters, every access has a known latency. DRAM exists only at tray level (up to 512 GB via fabric expansion logic plus host memory), not attached to the LPU.

Interconnect & system scale

Ninety-six chip-to-chip links connect LPUs within a tray, across trays through a cableless spine, and across racks. A plesiosynchronous protocol cancels clock drift so hundreds of LPUs behave as one statically scheduled machine.

With Vera Rubin, GPUs build the KV cache (prefill) and run decode attention, while LPX executes MoE expert FFNs on every token (attention–FFN disaggregation), orchestrated by NVIDIA Dynamo. LPX can also run the draft model for speculative decoding.

Programming & scheduling

The Groq compiler emits a complete cycle-level schedule covering compute, memory and network; there is no runtime hardware scheduler.

Why class C3

Compute, memory access and communication are all statically scheduled — the deterministic streaming subclass.
