05 — Scope and methodology

Designed as a living research resource, with conservative evidence practices.

Architectural classification

A1 SIMT/vector–tensor; B1 structured tensor arrays; B2 flexible tensor datapaths; C1 reconfigurable spatial fabrics; C2 distributed-memory manycores; C3 deterministic streaming; D1 model-compiled datapaths.

Dataflow, scratchpad, cacheless, CGRA-like, 3D and wafer-scale are cross-cutting attributes. Borderline industrial processors receive provisional classification notes.

Evidence & update policy

  • Prefer vendor datasheets, software/architecture manuals and conference papers; cite each chip's primary URLs.
  • Do not infer unavailable area, SRAM, die node, bandwidth or power from other generations.
  • Never compare cache capacity with scratchpad capacity without distinguishing their semantics.
  • Distinguish roadmap announcements, currently available parts and historical academic architectures.
  • Revalidate changed specifications before publishing an updated snapshot.

Maintenance model

This website is intentionally static, offline-capable and inspectable. Its dataset is stored in chips.json. Edit that file and run python build.py to regenerate this standalone page. Publish to GitHub Pages, Netlify or any static host.

Weekly research alerts are separate from publishing. A monitoring report does not autonomously modify a deployed site without a connected repository and deploy pipeline.

Why not a single ranking?

Nominal FLOPS, SRAM capacity, HBM bandwidth and system power can optimize different bottlenecks. Compare at consistent granularity (die/chip/module/card/rack), specify workload precision and sparsity assumptions, and treat interconnect scale-up vs scale-out independently.

Typical missing fields: die area, NoC bisection throughput, local SRAM bandwidth, actual steady-state energy and real-world model performance.
